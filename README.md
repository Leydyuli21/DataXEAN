# Descripción del proyecto

Este repositorio contiene el desarrollo de un proyecto de análisis de datos aplicado a la empleabilidad universitaria, utilizando herramientas de ciencia de datos para transformar información en conocimiento útil.
Durante el proyecto se realizó la exploración, preparación y análisis de un conjunto de datos, considerando la calidad, estructura y comportamiento de las variables.
Se aplicaron técnicas de limpieza, transformación, análisis estadístico descriptivo y visualización para identificar patrones y relaciones relevantes.
Los resultados obtenidos permitieron interpretar el comportamiento de los datos mediante medidas estadísticas y representaciones gráficas.

Objetivo general

Identificar los principales factores que influyen en la empleabilidad de estudiantes universitarios mediante técnicas de análisis estadístico y modelos predictivos.

🔢 NumPy
📊 Matplotlib
